## 開発プロジェクト

### 1. YORUMICHI - 夜道の安全ナビゲーションシステム

**概要**:
夜間の外出における「安全なルート選択」という社会課題を解決するWebアプリケーション。複数のオープンデータを統合し、独自のA*アルゴリズムで「明るさ」「人通り」「緊急避難先」を総合評価した最適な夜道ルートを提案。

**東京都知事杯オープンデータハッカソン2025のサービス開発部門でファイナリストに選出**

**技術スタック**:
- Python (Flask), NumPy, Pandas, GeoPandas
- Google Routes API, A*アルゴリズム（安全性評価関数拡張版）
- Shapely（地理空間データ処理）, HTML/JavaScript（フロントエンド）

**工夫した点**:

1. **データ統合の工夫**:
   - 不審者情報、地区別犯罪統計、街灯位置、夜間光データ、人流データという5種類の異なるオープンデータを統合
   - 各データに対して正規化処理（2-98パーセンタイルでのクリッピング）を実装
   - 犯罪2.0、地区犯罪1.2、暗さ1.8、人流の少なさ1.0、街灯の少なさ6.0という重み付けパラメータを設定ファイルで調整可能な設計

2. **アルゴリズムの革新性**:
   - ターンペナルティ付きA*探索アルゴリズムを実装
   - Google Routes APIで取得した標準ルートの周辺2-5kmに50m解像度のグリッドを生成
   - 各グリッド点で5層データから危険度を算出
   - 20度以上の曲がり角にペナルティを課すことで、安全かつ歩きやすい経路を探索

**リンク**:
- GitHub: https://github.com/ryohei-iwamoto/yorumichi
- ハッカソン詳細: https://odhackathon.metro.tokyo.lg.jp/collection/86/?year=2025
- サービスリンク：https://yorumichi.com

### 2. DevInsights - 開発時間可視化システム

**概要**:
開発時間の自動計測・可視化システムです。VS Code拡張機能でコーディング時間を記録し、Discord Botで週次ランキングを自動配信。サークル全体の開発活動を可視化し、モチベーション向上とサークル活性化を目指したツールです。

**技術スタック**:
- VS Code拡張機能: TypeScript
- バックエンド: Go言語
- データストア: Google Cloud Firestore
- サーバーレス実行基盤: Cloud Run
- 定期実行: Cloud Scheduler
- Discord通信: discordgo
- CI/CD: GitHub Actions

**工夫した点**:
- 所属サークルの「メンバーの活動が見えにくい」という課題を解決
- VS Code拡張機能がコーディング時間を言語別に記録し、週次ランキングをDiscord Botが自動配信
- 当初はAWS Lambdaで開発していましたが、デバッグの困難さから開発者体験に優れるCloud Runへインフラを移行し、生産性を向上
- 時間計測機能は実績あるOSS（WakaTime）をフォークし、Discord Botもライブラリのサポート終了を受けPythonからGoへ切り替え

**成果**:
サークル内では技術相談が活発になったり、オンラインでは見えなかった互いの頑張りを認め合えたりと、コミュニケーションの活性化と一体感の向上に貢献しました。

### 3. Markdown Inline Preview - VSCode拡張機能

**概要**:
VS Code上でMarkdownファイルの装飾をリアルタイムに反映する拡張機能です。プレビューウィンドウを開かずにエディタ内で直接、見出し・リスト・コードブロックなどの視覚的な確認が可能になります。

**技術スタック**:
- TypeScript, VS Code Extension API, Decorations API
- CI/CD: GitHub Actions

**工夫した点**:
- 私は「人生はPDCAサイクルを回した分だけ成長する」という信念のもと、週次振り返りをMarkdownで記録し、AI（Codex・Claude Code）を活用してフィードバックを受ける習慣を実践
- VS Codeに移行後も「Markdownをプレビューなしで視覚的に確認できない」という生産性の課題に直面し、自ら最適解を開発
- JavaScriptで軽量に動作するよう設計
- 見出しやチェックボックス、コードブロックなど各要素に対してVS CodeのDecorations APIで装飾を適用
- 50ミリ秒のデバウンス処理で編集中の無駄な再描画を抑制
- テーブル整形機能では日本語文字幅の計算に対応

**リンク**:
- GitHub: https://github.com/kkaiki/markdown-inline-preview
- VS Code Marketplace: https://marketplace.visualstudio.com/items?itemName=markdown-inline-preview.markdown-inline-preview
